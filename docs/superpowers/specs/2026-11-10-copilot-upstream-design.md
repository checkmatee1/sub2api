## 方案选择

建议：独立 Copilot 适配服务 + fork 中的接入配置、运维文档及必要代码。链路为客户端 → Sub2API → 适配服务 → Copilot。先确认现有适配实现的维护状态与协议能力；若采用官方 SDK，必须禁用与模型转发无关的执行工具，并明确其 Agent 语义与普通聊天协议的差异。不能将 SDK 直接等同于 OpenAI 模型接口。

备选：在 Sub2API 内原生实现 Copilot 登录和令牌续期。组件较少，但认证、网关及前端改动范围更大，后续升级维护成本较高。

上述建议为实施者选择，尚待用户确认。
